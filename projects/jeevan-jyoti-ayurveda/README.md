# Jeevan Jyoti Ayurveda – 2026 redesign

Static redesign of https://jeevanjyotiayurveda.hsim.site/ (7 pages: Home, About, Consultation, Treatments, Conditions, Pricing, Contact).

- All text, prices, contact details, logo and photographs are the originals from the live site (`assets/images/`). Nothing was invented.
- The site has no products, testimonials or blog, so none are included. The WordPress sample "Hello world" post and "Sample page" were skipped.
- Booking form keeps the original behaviour: it opens WhatsApp with the details filled in.
- Open `index.html` directly, or serve the folder: `python3 -m http.server`.
- Fonts: Fraunces and Hanken Grotesk via Google Fonts (system fallbacks if offline).

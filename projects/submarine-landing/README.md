# Submarine Tour – Landing Page

Foreign tourists ke liye CRO-based landing page (single file, no build step).

## Chalane ka tarika
`index.html` ko browser me kholo.

## Apna content lagao (`assets/` folder me)
| File | Kahan dikhega |
|------|----------------|
| `assets/hero.mp4` + `assets/hero.jpg` | Header background video + poster |
| `assets/gallery/g1.jpg … g8.jpg` | Gallery (family / solo / party) |
| `assets/features/*.jpg` | Submarine ke andar ki cheezein (6 cards) |
| `assets/party.jpg` | Deck party section |

Image na ho to gradient + emoji placeholder dikhta hai.

## CRO elements
Benefit-led headline, above-the-fold booking form, trust bar, limited seats, 3-step flow, social proof, anchor pricing + "most popular" plan, risk-reversal guarantee, FAQ objections, sticky mobile CTA.

## Replace karna hai
Brand name, prices, reviews/stats (abhi sample hain), form endpoint (`script` me TODO).

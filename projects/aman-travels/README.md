# Aman Travels Website

Karnal ki travel agency ke liye static website (HTML, CSS, JS). Koi build step nahi hai.

## Pages

| File                 | Page                                              |
|----------------------|---------------------------------------------------|
| `index.html`         | Home                                              |
| `services.html`      | Services (9 services, har ek ka section)          |
| `about-contact.html` | About, contact details, map, enquiry form         |
| `blog.html`          | Blog (3 starter articles)                         |

## Chalane ka tarika

`index.html` ko browser me khol do, ya `python3 -m http.server` chalao.

## Hosting se pehle badalna hai

- `https://www.YOUR-DOMAIN.com` ko asli domain se replace karo (canonical tags, schema, `sitemap.xml`, `robots.txt`).
- Enquiry form WhatsApp (+91 92530 30998) par message kholta hai. Number `js/main.js` me hai.
- Client se confirm karke asli photos, Google reviews aur packages jodo.

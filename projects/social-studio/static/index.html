Social Studio

To use AI, first add your Gemini API key in Settings.

Create content

Make one piece of content right now. No calendar needed.

It keeps working in the background. You can switch tabs while the AI writes (keep the black window open).

The calendar is optional. Use it only if you want to plan posts ahead (for example a whole month).

Tip: drag a post onto another day to change its date. Click a post to edit it.

Brand Profile

Fill this once. The AI uses it to write content that sounds like you.

Settings

Your key is stored only in the data/ folder on your computer and is never uploaded.

Plan the month with AI

The AI will suggest days, formats and topics for the whole month. You can edit everything afterwards.

This runs in the background. You can keep using the tool while it works.

# HSIM Internship

Internship ke dauraan kiye gaye kaam, notes aur projects ka repository.

## Folder structure

| Folder       | Kya rakhna hai                                    |
|--------------|---------------------------------------------------|
| `projects/`  | Har project ka apna sub-folder (code + README)    |
| `notes/`     | Daily/weekly notes, learnings, meeting notes      |
| `resources/` | Useful links, docs, reference material            |

## Kaam karne ka tarika

1. Naya kaam shuru karne se pehle naya branch banao: `git checkout -b feature/<naam>`
2. Chhote, saaf commits karo.
3. Kaam pura hone par pull request kholo aur `main` me merge karo.
